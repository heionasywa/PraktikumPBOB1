# Solusi Pertemuan 1: Pengenalan Class dan Object

## Materi
- Konsep Class dan Object
- Atribut dan Method
- Konstruktor
- Getter dan Setter

## Tugas
Buat class `Titik` yang merepresentasikan titik pada koordinat (x, y) dengan operasi-operasi dasar:
- Membuat titik dengan koordinat (0,0)
- Mengatur dan mendapatkan koordinat
- Menggeser titik sejauh x dan y
- Mencetak koordinat titik

## File yang Dikerjakan
- `Titik.java` - Class utama dengan atribut absis dan ordinat
- `MTitik.java` - Driver program

## Bug yang Diperbaiki
- Method `geser()` pada baris 44: Mengubah `ordinat = ordinat + x;` menjadi `ordinat = ordinat + y;`

## Hasil Test
```
Titik (3.0,4.0)
```

## Pembelajaran
- Pemahaman dasar OOP dengan class sederhana
- Penggunaan konstruktor default
- Implementasi getter dan setter
